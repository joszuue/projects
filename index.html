Proyectos destacados

Selección de desarrollos y sistemas diseñados para resolver necesidades institucionales y técnicas.

Proyecto destacado 01

STEAM Maker Challenge Live Scoring System

Sistema de puntuación en tiempo real desarrollado para administrar competencias del STEAM Maker Challenge. Permite registrar equipos, gestionar enfrentamientos, controlar puntuaciones y mostrar resultados actualizados durante el desarrollo del evento.

02

FORMA

Sistema de gestión educativa orientado a organizar, administrar y dar seguimiento a diferentes procesos de formación. Centraliza información académica y facilita el control de los procesos educativos desde una plataforma digital.

03

Módulo de OKR

Módulo desarrollado e integrado en el Sistema de Información Institucional FUSALMO para gestionar objetivos y resultados clave. Permite registrar objetivos institucionales, asignar responsables, actualizar avances y visualizar el cumplimiento de resultados clave.

04

ECO System

Sistema para el estudio y medición del clima organizacional desarrollado para el Registro Nacional de las Personas Naturales de El Salvador. Permite recopilar información mediante evaluaciones, procesar resultados y facilitar el análisis del ambiente laboral dentro de la institución.
